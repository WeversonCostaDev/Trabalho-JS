# Trabalho-JS
Novo trabalho de desenvolvimento web com a implementação de javascript

O site terá a temática de uma loja virtual que vende cards

Para executar o programa use os comandos
1-npm install
2-npm run dev

O sistema tem dois lados, o do administrador e o lado do cliente, para acessar as página de cada um, é necessário estar logado em uma conta correspondente a este usuário.

O lado do administrado contar com funcionalidades como inserir um card, editar, excluir e fazer consultas.

O cliente possui funcionalidade de consulta e de compra ao adicionar o item no carrinho, podendo adicionar e remover itens do carrinho conforme a necessidade, também é possível fazer consultas com alguns filtros como o tipo de card ou o nome desse card, essas funcionalidades existem tanto para administrador quanto para o cliente.
